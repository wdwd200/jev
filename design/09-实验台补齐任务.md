## 边界

- 保留现有 API 主链路、Full/Jev 行为与明确未配置的 RAG。空结果、部分评分和服务失败不得伪造答案，不自动切换策略。
- 不接入真实 RAG，不做 QASPER、正式 F1、价格表、精确 tokenizer、p50/p95、部署或视觉重设计。
- 保留 `.env` 及现有 `.runtime/jev_context.sqlite3` 用户数据；不得输出密钥、读取并展示认证文件内容，或把秘密放入日志。
- 所有新数据库结构采用向后兼容迁移。先在旧 schema 的隔离数据库上验证，不能删除现有库重建。遗留记录缺少快照的地方标 unknown/legacy，不能拿当前设置冒充历史设置。
- 保留审计原始事实。不得删除失败用例、削弱断言、添加 xfail/skip 或硬编码示例结果来制造通过。只有实际公共契约变化时才调整检查方式，并说明对应要求仍如何被验证。
- 不引入新模型服务或自动重试风暴。后台以离线测试为主；必要的真实 API 小样本复核只使用已有 smoke 脚本，不运行大量调用。
- 每完成一个下面的批次，更新 `.runtime/sol-repair-progress.json`，写清已改文件、检查结果、下一项和阻塞原因；执行中断前也要记录可接续状态。不要因完成一个批次就把整个任务报为完成。

## 批次一：修复确定性错误和失败边界

对应 A01、A03、A04、A07、A08、A09、A10。

1. 校验 JSON/表单 mode；错误输入不新增问题、不产生选文或任何外部请求。
2. 作答校验响应结构和非空字符串；错误响应创建失败作答，不修改完成的选文。错误消息脱敏，兼容 usage 缺失。
3. Jev 校验概率为有限 [0,1]，无效概率按单块评分错误处理；所有失败为 failed，部分成功为 partial。
4. 明确验证问题、工作区、块所属文档、活动块集合及有效性。直接服务调用也应校验，不能只依赖路由选择正确输入。
5. 保存文档上传顺序并稳定读取；同分预算裁剪按文档顺序和块 ordinal；不能使用随机 ID 作为业务排序依据。
6. SQLite 连接在成功、异常时都关闭，保留事务提交/回滚语义。

通过条件：对应离线验收全部通过，原测试仍通过，补上表单错误模式、异常响应和实际传输错误回归。

## 批次二：指标、可追溯记录与最小版本操作

对应 A02、A05、A06、A11、A12、A13。

### 计数与证明

- 本阶段继续允许词数近似。明确区分正文近似规模、完整块上下文近似量（含重叠）、选中文本近似量、供应商实际报告的生成输入/输出 token。
- 上下文节省率用同一切块集合的完整上下文作为基线，Full=0。不要用正文词数或含提示开销的生成用量混算这一比例；可以同时展示这些原始量，但必须说明口径。
- 缺失供应商 usage 时记来源为 estimated 或 unavailable。费用未计算时用 null 和 not_calculated 等状态；Full 的筛选费用明确为 0；未知的其他费用不能当 0 加总。
- 增加最小只读对比/证明服务及独立持久化记录，引用选文/作答及版本。输出每模式上下文指标、费用可用性、选择耗时、作答耗时与其可计算的合计。未测端到端墙钟耗时时不要把耗时相加冒充端到端延迟。Answer-F1/Evidence-F1 为 not_run，缺少模式或失败时标明对比不完整。
- 保持业务计算在服务层，网页只编排/展示。不要要求建立正式评测系统。

### 快照与版本

- 选文所有状态固定输入 chunk_set_id、规则版本和已知规则参数、策略参数/模型/提示版本。作答固定使用的选文、生成模型及提示版本。
- 保存所有候选评分和错误，包含被阈值排除、预算排除的候选，而不只保存最终入选块。正常与失败用量都按已知程度记录。
- 配置改变有可识别的新配置指纹/版本；保留历史记录，不覆写旧参数。文档内容不可变的版本范围可使用文档 ID/内容哈希，不必引入生产文档修订系统。
- 先在 `03` 至 `07` 说明最小生命周期操作，再实现：显式重切生成新的块集合并切换活动版本；关联旧选文标为不可再用于新作答但仍可查询；显式选文重试产生新记录；显式作答重试产生新记录；旧作答保留。
- 不要求自动检测配置变化后后台重切。请求沿用已保存的块集合时，应明确记录其历史切块配置；发起重切时使用新配置。无效或过期输入必须拒绝，不能悄悄改成当前版本。
- 作废由各模块维护自身记录，不删除旧内容，不让证明模块修改选文/作答。对历史多次作答展示明确的顺序/引用，不能永远只返回第一次。

通过条件：A02/A05/A06 检查通过；新增迁移、参数变化、空/失败快照、重切失效、选文/作答重试、历史保留、unknown 用量及证明记录测试通过。数据库重开后结果仍一致。

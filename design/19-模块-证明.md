# 19 模块设计：证明

日期：2026-10-02
前一步：[18-模块-作答.md](18-模块-作答.md)

只设计证明模块。它只读文档、块、问题、选文和作答，不改那些记录。发现某一次不公平，只把这一次标成无效。

这一份是现行规则。2026-10-02 起，比较记录按这一份计分，并报告 p50 和 p95。

## 这个模块做什么

对同一道题、同一套块，汇总全文、Jev 和标准检索三次运行。它回答两件分开的事：选得准不准，答得对不对。同时报告少送了多少 token、费用和耗时。

证明不发起降级。用户提问时 Jev 不可用而改走检索，那是选文模块的事。证明要看三路时，三路都必须真的跑过。

## 参考的现成做法

| 来源 | 做法 |
| --- | --- |
| QASPER | 5049 题、1585 篇论文。答案用片段级 F1，一题有多个参考答案时取最高分。证据用段落、图和表的集合算 F1，多个证据标注时也取最高分。 |
| RAGAS 上下文召回 | 参考答案里有多少要点被检索到的内容覆盖。按编号计算时，是检索到的参考编号除以全部参考编号，分数在 0 到 1。 |
| RAGAS 上下文精确率 | 看有用的块排得靠不靠前，按每一名的精确率再平均。 |

本项目的题库分采用 QASPER 的两种 F1。RAGAS 的召回和精确率不并进主分数，因为它们用另一个模型拆要点，会引入第三套判断。

## 技术选型

主分数按 QASPER 的两种 F1 自己实现。答案按词重合，证据按页、种类和页内位置对齐。不接入 QASPER 的整套训练代码，那个仓库是另一个模型的基线。

不用 RAGAS。它的上下文召回要用另一个模型把参考答案拆成要点，分数就不再只取决于这三路。不用题库网站的在线打分，题目和 PDF 都留在本地。

记录继续写进现在的 SQLite。不另建评测平台。

## 两个分数

两个分数都换算成 0 到 100。没有作答的题不补 0 分，也不算进平均，单独计成未作答。

**Answer-F1** 看答得对不对。把回答和参考答案拆成词，去掉大小写、标点和 a、an、the。一题有多个参考答案时取最高分。Yes、No、Unanswerable 也按词比较。

**Evidence-F1** 看选得准不准。QASPER 比的是段落、图和表有没有被选中，不是把两边的原文接成一段再比词。一块只要和某一条标准证据来自同一页、同一种类、同一个页内位置，就算选中了该证据。多个证据标注时取最高分。

选中了但模型答错，只影响 Answer-F1。没选中，只影响 Evidence-F1。

代码里现在的 Evidence-F1 是两边文本的词重合。那不是 QASPER 的算法，不能继续当成这个分数。

## 三路怎么比

同一题先上传它对应的那一篇，切一次块。再分别跑全文、Jev、标准检索，各作答一次。三路用同一句原文，题库题不改写。

QASPER、FinanceBench、MultiHop-RAG 分开报告，不合成一个总分。图表才能回答的题排除。正文超过 80 万 token 的题作废，不截断后继续比。

QASPER 的暂定及格线仍是：Jev 的 Answer-F1 比全文低不超过 3 分，比标准检索低不超过 3 分。这是全部测试题的平均，不是每一题允许差 3 分。看完测试集结果后再改，这条线作废。金融和新闻的及格线还没定，必须在看它们的完整结果之前定。15 题试跑不是及格线。

Evidence-F1、token、费用和延迟只报告，不决定过不过。

## 少送了多少、费用和延迟

少送了多少，用这一问选中的块的 token，比这次参与选择的全部块的 token。不和原始正文比，因为标题和表头会重复。全文的节省率是 0。

费用分成选择、改写、生成三项。全文的选择费用是 0。改写只出现在用户追问，题库比较里这项是 0。没有价格表时费用保持未计算，不填 0。

延迟分开记录选择阶段和从提问到回答的总时间，报告 p50 和 p95，不用平均值代替。

## 一次证明记下什么

编号、题目、三份选文、三份作答、两个分数、未作答原因、token、三项费用、两段延迟、是否有效。记录创建后不因后来重切或重试而改写。

## 代码做到哪了

比较记录给每一路分别记 Answer-F1 和 Evidence-F1。没有参考答案或证据位置时，这一路标成未跑，不填 0。作答没有完成时标成未作答，不补 0，也不算进平均。

Answer-F1 按词重合，多个参考答案取最高分。Evidence-F1 按页、种类和页内位置对齐，多组标注取最高分。旧的证据文本词重合函数还留着，只给以前的检查用，不写入比较记录，试跑也不再用它。

题库下载下来的证据是段落文字，没有页码。试跑先用这段文字找到对应的块，再按那一块的页、种类和页内位置计分。对不上任何一块时，这一路标成未跑，不把词重合当成证据分。

每次比较和试跑都报告选择阶段、以及从提问到回答的 p50 和 p95。没有完成的阶段不补 0，也不用平均值代替。

# 18 模块设计：作答

日期：2026-10-02
前一步：[07-模块-选文.md](07-模块-选文.md)

只设计作答模块。它不改选文，不重新决定留哪些块，也不计算分数。

这一份是现行规则。2026-10-02 起，代码按这一份作答。图片能不能送进当前接口仍未确认，所以原图先不送。

## 这个模块做什么

读取一份已经完成的选文，把问题和留下的块交给同一个 DeepSeek，保存回答。全文、Jev 和降级检索各自有自己的选文，也就各自有自己的作答。

生成模型是 DeepSeek-V4.1-Flash，接口名 `deepseek-flash`。三路使用同一套提示。提示里不出现全文、Jev 或检索这些名称。

## 技术选型

生成只用 DeepSeek-V4.1-Flash，接口名 `deepseek-flash`。立项时已经定过，不换模型，也不用几个生成模型互相比。调用继续走现在的 HTTP 接口。

token 以接口返回为准。接口没有返回时，用 DeepSeek 公布的分词器估算，并标明是估算。不用一个英文单词算一个 token。

图片能否送入，等这个接口的官方说明确认。确认前不改用另一个支持图片的生成模型，否则三路比较就不再是同一个模型。

## 什么能作答

只有状态为完成、并且仍指向这次选择当时那批块的选文可以作答。空结果、部分完成、失败和已作废都不调用模型。空结果向用户显示这次没有形成证据。

作答失败时，选文不改。再试一次只新建一条作答，不重新选块。

## 送进去什么

送入的问题用选文已经记下的那一句。题库题是原文。用户追问是改写后的句子。

文字块送带标题的文字。表格块送 Markdown 表格。图片块送图注和图表说明。选文留下原图时，原图一并送入。DeepSeek 当前接口能不能接收图片，还没有从官方说明里确认。确认之前，原图留在选文上，作答先只送文字、表格和图注，并在作答上记下图片没有送出。

关闭思考。用户自己的提问要求短答案，但不限制成某个数据集的格式。题库作答要求短答案：原文短语、Yes、No 或 Unanswerable，不写解释。否则多出来的词会被扣分。

## 记下什么

编号、用的哪一份选文、模型名、提示版本、回答原文、输入 token、输出 token、费用、耗时、失败原因。

输入和输出 token 以接口返回为准。接口没返回时，才用 DeepSeek 分词器估算，并标明是估算。费用没有价格表时保持未计算，不填 0。思考已经关闭，所以不另记一笔思考 token。

改写问题的费用记在问题上，不记在这条作答里。

## 代码做到哪了

作答使用改写后的问题，思考关闭。文字、Markdown 表格和图注会送出。选文里有原图时，作答记下图片没有送出，不把图片字节放进请求。输入和输出 token 优先用接口返回的数。没有价格表时费用保持未计算。

# 16 模块设计：切块

日期：2026-09-30
前一步：[06-模块-文档.md](06-模块-文档.md)

只设计切块模块。它读取文档模块已经抽出的文字、表格和图片。选文阈值、检索留几块、作答提示都不在这一份里。

这一份是现行规则。2026-10-02 起，代码按这一份切块。没有装 Docling 时，用本地的同样规则，不调用它的切块类。

## 这个模块做什么

把一次对话里每份 PDF 的内容切成可以挑选的块。新问题只能从还留在这次对话里的块中选。

加一份 PDF，只切这一份，把它的块加进当前这批。删一份 PDF，只去掉属于这一份的块。其他文件的块不重切，编号也不变。

## 参考的现成做法

三家都不是按固定词数把全文滑开，也都不是把表格从一行中间切开。

| 来源 | 做法 |
| --- | --- |
| Docling HybridChunker | 先按版面元素成块，再按调用方提供的分词器把过大的块切开。同一标题下过短的块默认合并。表格切开时默认重复表头。它没有默认的 token 上限，也没有重叠。 |
| Unstructured | `by_title` 按标题聚合。硬上限默认 500 个字符，重叠默认 0，只在一块被切开时才带上前一块的尾部。表格不和其他元素合成一块，只有超过上限才切开。图片留在元素的元数据里。 |
| RAGFlow | 用模板按文档类型切，切完可以看见边界并改。表格由 DeepDoc 按表格结构识别，不并进普通段落。 |

本模块采用 Docling 的切法，因为文档模块已经用 Docling 得到文字、表格和图片。上限用 Unstructured 的原则：默认不重叠，表格单独成块。不采用 RAGFlow 的整套模板和检索，否则整篇、检索和 Jev 不再是同一套块。

`design/15` 里写过 256 个 token、重叠 32。那是词数窗口，会把表格和图片从中间切开，不再使用。

## 技术选型

切块用 Docling 的 HybridChunker，分词器换成 DeepSeek 公布的那一个。文档模块已经产出 Docling 的结果，同一份结果接着切，页码和标题不会丢。HybridChunker 按调用方给的分词器把过大的块切开，同一标题下过短的块合并，表格切开时重复表头。

不用 Unstructured 的 `by_title`。它的默认上限是 500 个字符，和 DeepSeek 的 token 不是同一把尺子。也不用 RAGFlow 的模板切分，那会带进另一套检索。不自己按词数滑动，那会把表格和图片从中间切开。

## 三种块

按 Docling 的阅读顺序切。页眉和页脚不进入块，来源记在块上。段落内的折行已经在文档模块拼回去，切块不再按折行断开。

- 文字块：同一标题下的段落。过短的相邻段落合并，合并后不超过上限。块的开头带上标题。
- 表格块：一整张 Markdown 表格。超过上限时按行切开，每一块重复表头。不从一行中间切开。
- 图片块：一张图是一块，不切开。挑选时读图注和图表说明。原图跟着这块保存。图注超过上限时，只切图注，每一段仍指向同一张原图。

## 上限

一块最多 512 个 token。用 DeepSeek 公布的分词器数，中文和英文都走这个分词器。

不设置重叠。块和块的衔接靠重复标题或表头。表格如果重叠，同一行会出现两次。

512 不是这三家给出的默认值。Docling 要调用方自己提供上限，Unstructured 的默认是 500 个字符，检索模型 `bge-m3` 最长能读 8192 个 token，但没有推荐块大小。512 取在它们之间：一块能装下一张普通表格，又不会把许多节合成一块。

## 增加、删除、重切

每块只属于一份 PDF。当前可挑选的块，是还没被删除的那些 PDF 的块。

- 增加：只切新的那一份。加上后会超过 80 万 token 的，文档模块不会收下这一份，切块也不发生。
- 删除：删掉属于这一份的块。已经答过的题不改，当时选中的文字和图片留在那次选文上。
- 重切：只有切块规则变了才做。当前还在的每一份都重新切，旧块保留但不能用于新问题。加文件和删文件都不算重切。

## 一块记下什么

编号、属于哪份 PDF、在这份 PDF 里的顺序、种类、用来挑选的文字、token 数、切分规则。图片块再记下原图。表格块的文字就是那张 Markdown 表格。

每一块还要记下从哪来。只写“第几份 PDF”不够，一页里会有多块，答案旁边要能点回那一页。

| 来源 | 含义 |
| --- | --- |
| 文件 | 哪一份 PDF，用文档编号和上传时的文件名 |
| 页 | 从第几页到第几页。一块跨页时两页都记下 |
| 位置 | 这一页里的阅读顺序，第几段、第几张表或第几张图 |
| 标题 | 这一块上面的各级标题。没有标题就空着 |

这些来自 Docling 解析时已经知道的页码、阅读顺序和标题，不从页眉里再猜。选文和作答只复制这些来源，不改它们。页面展示答案时，用文件名和页码标出证据。

## 和“少送了多少”的关系

页面上少送了多少，用这次选中的块比这次对话里全部的块。不和原始正文比，因为标题和表头会重复，切完的合计可以比正文大。

## 代码做到哪了

默认 512 个 token、不重叠。短段落在同一标题下合并，表格按行切开并重复表头，一张图单独成块。每块记下文件名、页码、页内位置和标题。添加或删除一份 PDF 只改这一份的块。整批重切仍然保留旧块，只是旧选文不能继续作答。

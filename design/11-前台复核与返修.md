## 首轮复核事实

首轮后台已把 `audit_acceptance.py` 提升到 18 passed，并保留原有回归通过。前台审查代码及补充检查发现，仅凭这两组测试尚不足以证明 A01-A15 全部完成。

新增 `tests/audit_frontend_followup.py`；第一次检查为 4 passed / 4 failed，记录在 `.runtime/frontend-followup-before.txt`。该次检查发生在后台最后收尾期间，后续必须对最终代码重跑；其中问题归属校验在紧接着的代码读取中已经看到补丁，不能把这个旧失败数字当最终结果。

可重复的问题包括：

1. **跨文档同分排序**：`source_order` 使用 `(doc.id, index)` 为键，却以 `(document_id, 0)` 取值，使非首文档回退为 0，最后再次按随机 chunk ID 决定取舍。单文档两块测试不足以检出这个问题。
2. **生成输入估算**：缺少供应商 usage 时仍只把选中文本词数作为输入，漏掉了实际请求中的提示与问题。允许近似，但要估算实际拼接的请求内容并声明不包含精确 chat framing。
3. **失败调用的已知用量**：响应已带 `prompt_tokens/completion_tokens`，但 content 为空时先抛错，导致已知用量被记成 0/unavailable。应保留可解析的 reported usage，同时作答状态仍是 failed。
4. **异常响应结构与问题归属**：前台补充文件覆盖 None/list/嵌套 None，以及 selection 与另一问题不匹配。这些检查须保持通过。

## 尚未落实的原任务要求

首轮 `10` 中以下“已修复”判断缺少实现支撑，必须补完后再更新结论，不能改小验收范围：

### A06 / A13：输入配置和生命周期

- 当前只存 chunk_set_id 和少量 rule_params，不等于记录了历史切块参数。尤其 Jev 从当前 config 取 chunk_version，会把新配置写到仍在使用的旧块上。
- 工作区/块集合要保存建立时的切块规则参数、计数口径、可识别配置指纹；选文快照复制实际块集合的信息。生成作答也要保存提示版本。
- 实现 `POST /workspaces/{workspace_id}/rechunk`：使用当前配置产生新块集合、切换活动版本，保留旧块与作答，旧选文不可再用于新作答。拒绝 rejected 工作区，不作自动后台重切。
- 实现 `POST /selections/{selection_id}/answers/retry`：只重试生成，不重新选文；保存新作答，保留原作答。拒绝非 complete、已作废、过期输入和 legacy 无法确认输入版本的选文。
- 保留选文重试接口；同输入重试创建新记录并保留旧记录。单纯重试无需自动把旧成功结果作废，输入失效或显式作废时再改变有效性。不能用“重试”悄悄把旧输入换成新块集合。
- 运行响应保留兼容字段 `answer`（明确为最新一次），并通过 `answers` 数组或清晰的独立历史入口暴露全部作答；当前 next(first) 会在作答重试后仍展示第一次。
- 旧 schema 中真实存在的数据必须迁移保留。用非空旧表样本做测试；空的现有用户库初始化成功不等于验证了历史数据迁移。
- 无法从旧记录恢复的切块参数/提示版本/用量来源标 unknown 或 legacy，禁止套用当前配置。

### A12：独立对比记录

- 把 metrics 字典放在 `_selection_payload` 里，不等于旧任务要求的独立证明服务和持久化记录。
- 实现一个只读业务事实的比较服务，写入自己独立的比较表/记录；记录引用明确选文和作答 ID 及版本，不修改它们。
- 提供 `POST /questions/{question_id}/comparisons` 创建快照、`GET /questions/{question_id}/comparisons` 列表、`GET /comparisons/{comparison_id}` 读取；若已有等价入口，文档明确即可。比较不调用模型。
- 保存正文近似规模、完整块上下文近似规模、选中上下文、相同口径节省率、生成用量来源、各阶段耗时、费用可用性。F1 明确 not_run；模式缺失、失败或输入不一致时标记 incomplete/invalid 等原因。
- Full 选择费用为 0；其他未知费用不可当 0 汇总。阶段耗时缺失时不能用 0 补齐再声称总耗时精确；如果相加，标为已测阶段合计而不是端到端墙钟。
- 证明规则计算放服务层，页面只展示。已有证明快照在后续重试/重切后仍可复核，旧引用保持不变，并能看出当前有效性。
